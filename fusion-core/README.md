# Fusion core (server and optimizer)

Shared code used by both the server and the optimizer: types, configuration, exceptions and the Thrift API (generated in `src/main/gen-java`), the Iceberg catalog and table wrappers, the evaluators and planners the server uses to decide what to compact, and the readers, writers and rewrite executors the optimizer uses to rewrite files. Because the server and the optimizer can run different versions during a rollout, anything serialized between them must stay compatible.

## Packages

Each package has a README with its role, key classes, flows, threads, contracts, extension points, pitfalls and tests.

| Package | What it does |
| --- | --- |
| [`io.olake.fusion.api`](src/main/gen-java/io/olake/fusion/api/README.md) | Java classes generated by the Apache Thrift 0.20.0 compiler from Fusion's Thrift IDL. |
| [`io.olake.fusion`](src/main/java/io/olake/fusion/README.md) | The root package of `fusion-core`: the format-neutral catalog and table abstractions, the table format registry, the server's table-runtime and process-plugin interfaces, error codes, and the string constants that the server and the optimizer exchange. |
| [`io.olake.fusion.aws`](src/main/java/io/olake/fusion/aws/README.md) | One AWS SDK v2 credentials provider, `StaticAwsCredentialsProvider`. |
| [`io.olake.fusion.client`](src/main/java/io/olake/fusion/client/README.md) | Thrift client plumbing for calling the Fusion server: `thrift://` URL parsing, a pooled thrift client with one-shot proxies, the JVM-wide cache of `OptimizingService` clients, and a generic `ClientPool` copied from Iceberg. |
| [`io.olake.fusion.config`](src/main/java/io/olake/fusion/config/README.md) | The typed configuration framework (`ConfigOption`, `ConfigOptions`, `Configurations`, `ConfigHelpers`), adapted from Apache Flink, and the per-table configuration objects (`TableConfiguration`, `OptimizingConfig`, `DataExpirationConfig`, `TagConfiguration`). |
| [`io.olake.fusion.config.shade`](src/main/java/io/olake/fusion/config/shade/README.md) | The `ConfigShade` SPI: a pluggable way to decrypt sensitive values (passwords) in the server configuration before the server uses them. |
| [`io.olake.fusion.config.shade.impl`](src/main/java/io/olake/fusion/config/shade/impl/README.md) | Built-in `ConfigShade` implementations. |
| [`io.olake.fusion.config.shade.utils`](src/main/java/io/olake/fusion/config/shade/utils/README.md) | `ConfigShadeUtils`: loads the `ConfigShade` implementations, defines the two `shade.*` options, and decrypts the sensitive entries of the server configuration map. |
| [`io.olake.fusion.data`](src/main/java/io/olake/fusion/data/README.md) | File-level types inherited from Amoro's mixed format: file types, the hash tree node, file-name parsing and a `DataFile` wrapper. |
| [`io.olake.fusion.events`](src/main/java/io/olake/fusion/events/README.md) | The event model and the listener plugin interface. |
| [`io.olake.fusion.exception`](src/main/java/io/olake/fusion/exception/README.md) | Fusion's exception hierarchy. |
| [`io.olake.fusion.formats.iceberg`](src/main/java/io/olake/fusion/formats/iceberg/README.md) | Iceberg implementation of Fusion's format-neutral catalog and table API: builds the Iceberg catalog from catalog properties and wraps each loaded Iceberg table so that every operation runs with the catalog's credentials. |
| [`io.olake.fusion.formats.iceberg.maintainer`](src/main/java/io/olake/fusion/formats/iceberg/maintainer/README.md) | Iceberg implementation of `TableMaintainer`: orphan file cleaning, dangling delete file cleaning, snapshot expiry, data expiry and automatic tags. |
| [`io.olake.fusion.formats.iceberg.utils`](src/main/java/io/olake/fusion/formats/iceberg/utils/README.md) | Helpers for Iceberg table maintenance: snapshot lookup, the sets of files a table still references, dangling delete detection, and a batched file deleter. |
| [`io.olake.fusion.hive`](src/main/java/io/olake/fusion/hive/README.md) | Hive Metastore (HMS) clients: `HMSClient`, `HMSClientImpl`, `AuthenticatedHiveClientPool`. |
| [`io.olake.fusion.iceberg`](src/main/java/io/olake/fusion/iceberg/README.md) | Holds one constant class, `io.olake.fusion.iceberg.Constants`, with `INVALID_SNAPSHOT_ID = -1L`: the value Fusion uses for "no snapshot". |
| [`io.olake.fusion.io`](src/main/java/io/olake/fusion/io/README.md) | File access for Fusion tables: an `org.apache.iceberg.io.FileIO` extension that can run calls as an authenticated user, plus small helpers for closing iterators and a (disabled) table trash. |
| [`io.olake.fusion.io.reader`](src/main/java/io/olake/fusion/io/reader/README.md) | Readers that turn the input files of one optimizing task into live rows (deletes applied) and deleted rows (to be rewritten as position deletes). |
| [`io.olake.fusion.io.writer`](src/main/java/io/olake/fusion/io/writer/README.md) | Writers that produce the output files of a compaction task: partitioned data files and per-data-file position-delete files. |
| [`io.olake.fusion.log`](src/main/java/io/olake/fusion/log/README.md) | `OptimizingTaskLogContext`: puts the optimizing process id and task id into the Log4j2 `ThreadContext` of the thread that runs a task, so that task logs can be tagged and routed per task. |
| [`io.olake.fusion.maintainer`](src/main/java/io/olake/fusion/maintainer/README.md) | Format-neutral API for table maintenance (orphan file cleaning, dangling delete cleaning, snapshot expiry, data expiry, tag creation) and the context a maintainer gets from the server. |
| [`io.olake.fusion.metrics`](src/main/java/io/olake/fusion/metrics/README.md) | A small metrics API: metric definitions with tags, counters and gauges, a registry, and the plugin interface for reporters. |
| [`io.olake.fusion.op`](src/main/java/io/olake/fusion/op/README.md) | Wrappers around Iceberg table operations and snapshot updates. |
| [`io.olake.fusion.optimizing`](src/main/java/io/olake/fusion/optimizing/README.md) | Shared types of one compaction ("optimizing") run: the task input and output that travel between the server and the optimizer, the rewrite executor that the optimizer runs, and the metrics and state records the server keeps. |
| [`io.olake.fusion.optimizing.evaluation`](src/main/java/io/olake/fusion/optimizing/evaluation/README.md) | Metadata-based evaluation: cheap checks, from snapshot summaries and file-size statistics, that can declare a table or partition "not worth evaluating" without a full plan. |
| [`io.olake.fusion.optimizing.plan`](src/main/java/io/olake/fusion/optimizing/plan/README.md) | Decides, per partition, whether a table needs Minor, Major or Full compaction, and splits the chosen files into rewrite tasks (`RewriteStageTask`). |
| [`io.olake.fusion.optimizing.scan`](src/main/java/io/olake/fusion/optimizing/scan/README.md) | File scan used by the evaluator and planner: lists every live data file of a snapshot together with the delete files that apply to it. |
| [`io.olake.fusion.process`](src/main/java/io/olake/fusion/process/README.md) | Generic process and task model: process status enums, persisted process state, the `StagedTaskDescriptor` that carries a task's input/output, and `SimpleFuture` used to signal task and process completion. |
| [`io.olake.fusion.properties`](src/main/java/io/olake/fusion/properties/README.md) | String constants for catalog properties (`CatalogMetaProperties`) and table location keys (`MetaTableProperties`). |
| [`io.olake.fusion.resource`](src/main/java/io/olake/fusion/resource/README.md) | The model for optimizer resources: `ResourceGroup` (an optimizer group), `Resource` (one optimizer instance), the container interfaces that start and stop optimizers, and `ResourceManager` for persisting groups and resources. |
| [`io.olake.fusion.scan`](src/main/java/io/olake/fusion/scan/README.md) | `TableEntriesScan`, a reader of Iceberg manifest entries (the `ENTRIES` / `ALL_ENTRIES` metadata tables) that returns each file with its snapshot id, sequence number and status, plus a few scan-task types. |
| [`io.olake.fusion.serialization`](src/main/java/io/olake/fusion/serialization/README.md) | Object serializers behind `utils.SerializationUtil`: Java serialization (`SimpleSerializer`) and Kryo (`KryoSerializer`, plus `JavaSerializer`, which despite its name also uses Kryo). |
| [`io.olake.fusion.table`](src/main/java/io/olake/fusion/table/README.md) | The table model shared by server and optimizer: table interfaces, identifiers, the Hadoop/auth context (`TableMetaStore`), table property keys and defaults, and the table-runtime state API used by the server. |
| [`io.olake.fusion.table.blocker`](src/main/java/io/olake/fusion/table/blocker/README.md) | Client-side view of a table blocker: an object that, while alive, blocks some operations (`OPTIMIZE`, `BATCH_WRITE`) on a table. |
| [`io.olake.fusion.table.descriptor`](src/main/java/io/olake/fusion/table/descriptor/README.md) | The response types of the table pages of Fusion's REST API (`/api/ams/v1/tables/...`) and the `FormatTableDescriptor` interface that fills them. |
| [`io.olake.fusion.utils`](src/main/java/io/olake/fusion/utils/README.md) | Static helpers used across Fusion: catalog and property merging, cron evaluation, file deletion, SQL-filter parsing, statistics (Puffin) files, reflection, serialization and sizes. |
| [`io.olake.fusion.utils.map`](src/main/java/io/olake/fusion/utils/map/README.md) | Maps keyed by Iceberg `StructLike` that live in memory or spill to a local RocksDB when they grow too large. |
| [`org.apache.iceberg`](src/main/java/org/apache/iceberg/README.md) | `IcebergFindFiles`, a Fusion class placed in Iceberg's own package so it can use Iceberg's package-private manifest API. |
| [`org.apache.iceberg.data`](src/main/java/org/apache/iceberg/data/README.md) | `IcebergRecordWrapper`, a copy of Iceberg's `InternalRecordWrapper` that also converts UUID values. |

The Thrift definitions the generated API is built from are described in [src/main/thrift/README.md](src/main/thrift/README.md).
