# Fusion server (AMS)

The Fusion server. It runs in the Fusion container or pod and holds everything server-side: catalog and table discovery, the table runtime and its status, cron-driven scheduling, planning and committing of compaction runs, the Thrift service the optimizer calls, the REST API OLake-UI calls (`/api/ams/v1/...`), the terminal used for table settings, and persistence in PostgreSQL. Entry point: `io.olake.fusion.server.FusionServiceContainer`.

## Packages

Each package has a README with its role, key classes, flows, threads, contracts, extension points, pitfalls and tests.

| Package | What it does |
| --- | --- |
| [`io.olake.fusion.server`](src/main/java/io/olake/fusion/server/README.md) | The server's root package: the process entry point (`FusionServiceContainer`), the server configuration schema (`FusionManagementConf`), the Thrift service that optimizers talk to (`DefaultOptimizingService`), and the Iceberg REST catalog endpoints (`RestCatalogService`). |
| [`io.olake.fusion.server.authentication`](src/main/java/io/olake/fusion/server/authentication/README.md) | Pluggable password and bearer-token authentication for Fusion's HTTP API: the provider interfaces, the credential types, the default admin-password provider, and the factory that loads providers by class name and reads credentials from a request. |
| [`io.olake.fusion.server.bootstrap`](src/main/java/io/olake/fusion/server/bootstrap/README.md) | Makes sure Fusion's single optimizer group exists, as an external group, every time a node becomes leader. |
| [`io.olake.fusion.server.catalog`](src/main/java/io/olake/fusion/server/catalog/README.md) | Registers, validates, stores and loads the catalogs Fusion compacts tables from, and gives the rest of the server one `ServerCatalog` object per catalog to list and load Iceberg tables. |
| [`io.olake.fusion.server.dashboard`](src/main/java/io/olake/fusion/server/dashboard/README.md) | Fusion's HTTP layer: the route table and auth filter for `/api/ams/v1/...` (`DashboardServer`), the JSON mapper, and the server-side services the REST controllers use to read table metadata, API tokens, uploaded files and the overview cache. |
| [`io.olake.fusion.server.dashboard.component.reverser`](src/main/java/io/olake/fusion/server/dashboard/component/reverser/README.md) | Rebuilds a table's DDL history ("operations") for the table page: it turns each Iceberg `metadata.json` version into a schema and property snapshot that `DDLReverser` diffs into Spark SQL statements. |
| [`io.olake.fusion.server.dashboard.controller`](src/main/java/io/olake/fusion/server/dashboard/controller/README.md) | The REST handlers behind Fusion's HTTP API (`/api/ams/v1/...`, port `http-server.bind-port`, 1630 in `local-test/config.yaml`). |
| [`io.olake.fusion.server.dashboard.model`](src/main/java/io/olake/fusion/server/dashboard/model/README.md) | Request and response beans of the REST API. |
| [`io.olake.fusion.server.dashboard.response`](src/main/java/io/olake/fusion/server/dashboard/response/README.md) | The JSON envelope of every `/api/ams/v1` response (`OkResponse`, `ErrorResponse`) and the page wrapper for list endpoints (`PageResult`). |
| [`io.olake.fusion.server.dashboard.utils`](src/main/java/io/olake/fusion/server/dashboard/utils/README.md) | Static helpers for the HTTP layer: request signatures, the single-page token check, catalog property splitting, table statistics, optimizer-quota maths, and small formatting functions. |
| [`io.olake.fusion.server.events`](src/main/java/io/olake/fusion/server/events/README.md) | Built-in event listener plugins for the server. |
| [`io.olake.fusion.server.manager`](src/main/java/io/olake/fusion/server/manager/README.md) | Two things share this package: the server's plugin managers (metric reporters, event listeners) and the optimizer containers, which start and stop optimizer processes when asked through the REST API. |
| [`io.olake.fusion.server.optimizing`](src/main/java/io/olake/fusion/server/optimizing/README.md) | The server side of compaction. |
| [`io.olake.fusion.server.optimizing.maintainer`](src/main/java/io/olake/fusion/server/optimizing/maintainer/README.md) | Builds the table maintainers that the maintenance executors use (snapshot expiry, orphan-file cleaning, dangling-delete cleaning, data expiry, tag creation), and gives them the server state they need. |
| [`io.olake.fusion.server.optimizing.sorter`](src/main/java/io/olake/fusion/server/optimizing/sorter/README.md) | Comparators that decide which `PENDING` table `SchedulingPolicy` plans first when several tables are due at the same time. |
| [`io.olake.fusion.server.persistence`](src/main/java/io/olake/fusion/server/persistence/README.md) | Fusion's database layer: builds the PostgreSQL connection pool, creates and migrates the schema at startup, sets up MyBatis, and gives every server component the `PersistentBase` helpers that open, nest, commit and roll back sessions. |
| [`io.olake.fusion.server.persistence.converter`](src/main/java/io/olake/fusion/server/persistence/converter/README.md) | MyBatis `TypeHandler`s that turn Java values (maps, lists, epoch milliseconds, enums, serialized objects) into the text, timestamp and binary columns of Fusion's PostgreSQL schema and back. |
| [`io.olake.fusion.server.persistence.extension`](src/main/java/io/olake/fusion/server/persistence/extension/README.md) | A MyBatis language driver that expands a short `IN (#{name::number[]})` placeholder into a `<foreach>` over a collection parameter. |
| [`io.olake.fusion.server.persistence.mapper`](src/main/java/io/olake/fusion/server/persistence/mapper/README.md) | The MyBatis mapper interfaces: every SQL statement Fusion's server runs against PostgreSQL, written as annotations (`@Select`, `@Insert`, `@Update`, `@Delete`) on Java interfaces. |
| [`io.olake.fusion.server.process`](src/main/java/io/olake/fusion/server/process/README.md) | A generic framework, inherited from Amoro, for running table "actions" as tracked processes on pluggable engines. |
| [`io.olake.fusion.server.process.executor`](src/main/java/io/olake/fusion/server/process/executor/README.md) | The engine side of the generic process framework in [`..`](../README.md): an engine plugin interface, its name type, and the runnable that submits a process to an engine and polls it until it ends. |
| [`io.olake.fusion.server.resource`](src/main/java/io/olake/fusion/server/resource/README.md) | Server-side model and storage for optimizer groups, optimizer resources and registered optimizer instances, plus the static registry of configured optimizer containers. |
| [`io.olake.fusion.server.scheduler`](src/main/java/io/olake/fusion/server/scheduler/README.md) | `PeriodicTableScheduler`, the base class for every per-table background job in the server: the cron tick, the commit executor, cleanup jobs and the health score. |
| [`io.olake.fusion.server.scheduler.inline`](src/main/java/io/olake/fusion/server/scheduler/inline/README.md) | The server's per-table background jobs, each a `PeriodicTableScheduler`. |
| [`io.olake.fusion.server.table`](src/main/java/io/olake/fusion/server/table/README.md) | Keeps one in-memory `TableRuntime` per managed Iceberg table, discovers tables from the registered catalogs, and persists each runtime's status, configuration and state to PostgreSQL. |
| [`io.olake.fusion.server.table.blocker`](src/main/java/io/olake/fusion/server/table/blocker/README.md) | Table blockers: short-lived, renewable locks stored in PostgreSQL that stop named operations (for example optimizing) on one table while a client holds them. |
| [`io.olake.fusion.server.table.cleanup`](src/main/java/io/olake/fusion/server/table/cleanup/README.md) | Types that record when each table-maintenance job last ran for a table, so periodic schedulers can wait their interval across restarts. |
| [`io.olake.fusion.server.table.internal`](src/main/java/io/olake/fusion/server/table/internal/README.md) | Creation, loading, commit and drop of Iceberg tables whose metadata pointer is kept in Fusion's own database, used only by catalogs of type `ams` (Fusion's internal catalog). |
| [`io.olake.fusion.server.terminal`](src/main/java/io/olake/fusion/server/terminal/README.md) | Fusion's SQL terminal: runs a script of Spark SQL statements against one catalog in the background and keeps its logs and results in memory for polling. |
| [`io.olake.fusion.server.terminal.local`](src/main/java/io/olake/fusion/server/terminal/local/README.md) | The default terminal backend (`terminal.backend: local`): runs terminal SQL in a Spark session inside the Fusion server JVM. |
| [`io.olake.fusion.server.utils`](src/main/java/io/olake/fusion/server/utils/README.md) | Server-side helpers: the Thrift exception proxy, environment-variable config overrides, usage telemetry, process-id generation, gzip, precondition checks, and Iceberg helpers used by planning, health scoring and internal catalogs. |
